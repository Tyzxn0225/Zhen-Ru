# YKK

基于 Godot 4.5 的校史主题 2D 校园探索 RPG，包含校园探索、NPC 对话、阶段任务、拼图和推箱子玩法。

## 直接试玩

在 Windows 中双击项目根目录的 `最终版4.exe`。

可执行文件使用 Git LFS 管理。从 Git 克隆后，需要安装 Git LFS 并运行 `git lfs pull`，才能取得完整的可玩文件。

## 打开工程

使用 Godot 4.5 打开 `RPG260604/RPG260604/project.godot`。
